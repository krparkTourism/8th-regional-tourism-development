# 제8차 권역별 관광개발계획 현장실사 대상지 선정 대권별 협의회 시스템

문화체육관광부, 광역지방자치단체, 한국문화관광연구원이 함께 추진하는 **제8차 권역별 관광개발계획(2027~2031)** 대권별 협의회(8.19~8.21) 지원을 위한 인터랙티브 웹 대시보드입니다.

## 📌 주요 기능
1. **대권별 인터랙티브 뷰**: 중부권(8.19), 동남권(8.20), 수도·강원권(8.20), 호남권(8.21) 원클릭 전환
2. **네이버 지도 공간 매핑**: 네이버 지도 API v3(`Client ID: 0a9dh6il2x`) 기반 신규/소규모 관광단지 좌표 표출
3. **4대 핵심 장(Chapter) 탑재**:
   - 제1장: 현장실사 대상 선정기준 (3대 기준 및 실사단 구성 원칙)
   - 제2장: 신규 관광(단)지 및 주요 개발사업 현황 (시도별 전체 목록)
   - 제3장: 현장실사 검토 대상(안) 상세 및 사유
   - 조정위원 협의사항: 실사 대상 확정 및 8월 말~9월 일정 조율 가이드
4. **실시간 심의 및 취합**: 각 사업별 실사 선정/보류/제외 의결 및 회의록 클립보드 복사 기능

## 🚀 GitHub Pages 배포 방법
1. 본 리포지토리의 `Settings` 탭으로 이동합니다.
2. 좌측 메뉴의 `Pages`를 클릭합니다.
3. `Build and deployment` > `Source`를 **Deploy from a branch**로 설정합니다.
4. `Branch`를 **main** / `/ (root)`로 선택하고 **Save**를 누르면 수 분 내 웹사이트가 무료로 발행됩니다.
